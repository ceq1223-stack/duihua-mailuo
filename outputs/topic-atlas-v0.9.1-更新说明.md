# 对话脉络 v0.9.1 · 取消模型上下文必填

不再要求使用者查找和填写模型上下文容量、最大输出能力、能力依据或勾选核对确认。填写常规 API 服务、Key 和模型 ID 后即可抽取。

- 获取模型列表时，服务商若返回明确的能力字段，会自动带入当前模型；没有这些字段也不阻止整理。
- 能力未知时，按当前输入预算估算并规划完整请求；该预算用于控制单次输入大小，不会被标成模型真实上下文容量，也没有暗中新增输出上限。
- 接口返回明确上下文超限时，沿用现有的缩小轮数、长正文分片、补读分片和检查点恢复链路。固定提示词本身过长、接口拒绝请求等情况仍会明确报错；不保证所有模型都能承载同一份提示词。
- 已保存且对应当前模型的能力信息仍可用于输入输出约束；更换模型或服务地址不会套用旧信息。
- 保留现有图、原文、资料库、API Key 和兼容的整理进度，不因这个调整重新归纳历史。

输入预算、单次输出长度、分段轮数仍可保留默认值。这些是请求设置，与要求人工核对模型能力不同。

验证：401 项自动模拟检查、24 个脚本语法检查。新增覆盖未知能力抽取、完整请求预算、真实超限响应的模拟缩段、长单轮分片、无必填字段保存、接口能力自动带入及切换模型后的兼容性。没有调用付费 API，真实服务仍以其实际响应为准。

安装后在 edge://extensions 重新加载扩展，再刷新 ChatGPT 网页。侧栏版本应为 v0.9.1。然后直接点击“抽取关系图”即可；此前因为未核对能力而失败的任务也可手动续做。
