# 对话脉络 v0.7.11 · 排除工具调用、思考与过程说明

根据用户实际提供的原始接口诊断完成过滤，不按命令或关键词猜测消息性质。

- 工具接收对象、思考内容类型、analysis/commentary 通道、工具返回以及明确内部/隐藏标记均不进入整理正文。
- 正式回答及其中的代码、用户代码和引用保留。缺少通道标记的普通回答不一律删除。
- 采集时与整理请求准备时使用相同规则，并处理 AI 消息内有明确类型标记的内部内容块。
- 新采集保留必要结构标记；旧记录缺少标记时要求刷新重读，暂停模型调用。旧任务快照不能绕过保护。
- 新任务只复用与过滤后输入仍兼容的进度，不沿用受移除内容影响的旧摘要。可核对的旧完整关系图以待更新状态继续显示。
- 原始接口诊断功能保留；此版本不调整模型调用预算或纠正次数，也不批量删除资料库历史。

使用：edge://extensions 重新加载扩展 → 刷新目标 ChatGPT 网页，等待自动采集 → 点击“抽取关系图”新建任务。不要直接续做采用旧来源快照的任务。已启用自动整理时，依照原设置运行。

验证：314 项模拟检查、18 个 JavaScript 文件语法检查通过。规则依据用户实际诊断；更新后的真实 Edge 采集和付费模型请求尚未实测，未调用付费 API。
