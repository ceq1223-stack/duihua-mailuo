# 对话脉络 0.9.3 · Edge / ChatGPT

当前版本无需填写或确认模型上下文容量。只需常规 API 配置即可抽取；旧版能力必填说明已停用，详见文末 v0.9.1 更新。

支持 AI 独立生成的一句话主题介绍 brief：每个主题同时输出名称、介绍和详细摘要；目录使用“编号＋名称＋一句话介绍”，不再截取摘要代替。保留历史目录选择、按需补查、简洁侧栏、统一设置和旧图持续展示。

简介缺失、过长或多行时，先保存已验证的主题、轮次及证据，再单独调用模型补齐简介。补齐成功才发布新图；失败保留旧图和检查点，续做不重发已验证轮次。补齐同样产生 API 调用费用，本次最多 12 次目录请求。

点击侧栏“抽取关系图”按当前设置新建任务，旧失败任务保留记录但不阻挡新任务。只复用模型、提示词与来源仍兼容的进度；预算和分段轮数调整无需丢弃有效进度。“续做”继续使用原任务设置。完全相同的排队或运行任务会去重，避免重复计费。

后台任务统一记录失败阶段、错误编号、具体原因、主题或关系序号、所在轮次、失败字段及建议操作；区分分段归纳、合并结果和发布前检查。关系证据为空与证据全来自其他轮次分别提示；只记录诊断，不修改原有校验或自动纠正策略。可展开“错误诊断”查看结束原因、该步骤实际输出上限和接口提供的用量。不会保存模型回复正文、推理内容或 Key。旧任务只有概括错误时，无法补回过去的结束原因。历史主题选择采用任务的最大输出 Token 设置，不再固定限制为 2048；简介补齐最多 4096，连接测试最多 2048。达到输出上限仍暂停，不增加自动重试。

历史读取严格分为三步：目录阶段只选主题；归纳先读取所选主题完整摘要；摘要不足时，AI须说明原因才能申请该主题具体原文。代码拦截跳过摘要的原文申请。旧版直接读原文的检索缓存重新选择，已完成轮次仍保留；必要补读仍受输入预算与每段2次补查上限限制。

## 分层关系图与标题跳转

关系图按现有关系分层排布：主线向下、分支展开，独立起点不补造连线。回归默认在选中相关主题时显示，也可勾选全部回归。支持搜索、拖动画布、缩放、适应与展开到本地扩展标签页。

点击主题后展示“主题详细摘要 · AI 归纳”，下方“讨论标题”只列 R编号和本轮标题。点击标题切换到时间线，按对话、分支和轮次ID定位并高亮；时间线仍可点击“定位原消息”。无需重新调用AI即可使用旧图的新布局。

## 连接模型 API 并抽取关系图

1. 点击“API 设置”，选择 OpenAI（ChatGPT）、Kimi（Moonshot）、DeepSeek 或自定义兼容接口。
2. 填入服务商 API Key。默认临时保留，浏览器或扩展重启、重新加载后需重填。勾选“在本机记住 Key”才写入扩展本地存储；该存储未加密。可单独清除此服务 Key。
3. 填入模型 ID，或点击“获取模型列表”读取可选模型。获取列表不发送对话正文，也不能代替模型调用测试。
4. 点击“测试连接”，会使用当前填写的 Key、地址、模型及 JSON 模式发送一条简短测试请求。只收到 HTTP 200 不算通过：必须收到完整的非空模型回复；开启 JSON 模式时还要返回有效 JSON 对象。成功会显示所测模型和耗时。测试不发送对话内容，不修改保存的配置，可能产生少量 API 费用；失败不自动重试。
5. 点击“保存设置”，成功后自动关闭窗口；保存失败时留在窗口显示原因。保存或测试时仅申请所选 API 站点的访问权限。固定服务使用官方地址；其他 HTTPS 服务请选自定义，填写兼容 Chat Completions 的基础地址，例如 https://服务地址/v1。也接受以 /chat/completions 结尾的完整地址。
6. 可点击“提示词”调整主题粒度、摘要和关系规则。默认使用我们设计的主题归纳提示词，可恢复默认并保存。输出字段与原文引用校验保持固定。
7. 选择需要整理的对话及分支，点击“抽取关系图”。按钮上方会显示发送目标。此操作把所选分支正文、相关人工标注及适用的上次结果发送到所选 API，可能产生服务商费用。首次手动抽取后，这条对话会按资料库设置自动增量整理；可关闭自动整理。不发送其他分支、网页地址或登录令牌。
8. 完成后可切到关系图。点击主题查看摘要、对应轮次、原文摘录和关系依据，也可回到时间线查看每轮 You / AI 摘要；展开摘要可看已采集原文，继续支持“定位原消息”。

各服务分别保存 Key，自定义服务更换域名后不会沿用旧域名的 Key。Key 只用于请求你配置的服务，不出现在对话 JSON 导出和采集诊断中。网页内容脚本不能访问保存的 Key。

API 请求使用流式响应，每段通过原文与结构校验后保存进度；全部完成后才更新正式关系图。可取消请求；服务商可能已处理部分请求，费用以其记录为准。鉴权、余额、限流、超时、拒绝、无效 JSON 等错误会停止，不覆盖上次正式结果。明确的上下文超限或输出截断会缩小当前段后重试，最多缩小四次，无法继续拆小则停止。

原文引用不匹配时，在输入预算允许的情况下，最多针对当前段发起一次校正请求，可能增加调用费用。模型必须重新提供能通过验证的引用；不会自动用无关原文替换错误证据，也不会按相似度放过改写。仍不通过则停止，保留之前的分段进度。错误会区分未知轮次、未知消息、角色错误和摘录不一致，并指出第几轮，不显示原文正文。

正常匹配优先使用逐字原文。仅存在空白、中文排版换行、排版引号或零宽格式字符差异时，会匹配并还原为对应的真实原文片段，保存和导出的仍是正文中的原始文字。不会自动改动数字、措辞、否定或补入省略内容。摘录存在不等于关系判断正确，语义仍需人工核对。

## 长对话、Token 上限与增量更新

- 不再把整个分支一次性发给模型，也不再使用 300 轮／24 万字符的单次限制。按完整轮次分段，默认每段最多 6 轮；输出预算较小时还会减少轮数。
- API 设置中“单次输入预算”默认为估算 12000 Token，包含提示词、当前段正文及上下文摘要。不同模型的编码方式不同，估算不是精确 Token 数；实际仍以服务商返回为准。输入预算加上最大输出长度，应小于所选模型的上下文容量，并留出余量。
- 每段仅发送该段原文、人工标注、相关旧主题摘要及最近两轮摘要。不会重发所有历史正文或完整旧关系图。检索最多 24 个旧主题辅助归类，跨段关系仍须有本段原文证据；远距离关系可能遗漏，应在图中核对。
- 本机按主题 ID 和名称合并结果，保留推进、分支、回归和原消息引用。每段验证后保存进度，全部完成才更新正式图。
- 输入中的 R5、R5M1 等短编号只用于辅助模型引用，不是平台消息锚点；保存时映射回本机原始消息 ID。升级至本版不会仅因新增短编号或原文候选而作废 v0.5.0 已完成的进度。
- 默认勾选“优先复用结果，只处理新增轮次”。正文与标注完全不变、仅追加完整新轮次时，只发送新增轮次；没有变化时不调用模型。成功的分段中断后可点击同一按钮续做。
- 修改旧正文、人工标注、平台路径、模型、服务地址或提示词时，不混用不兼容的旧结果。旧版本结果首次升级后需重新整理一次。仅调整分段预算或输出长度，仍可复用已完成进度；关闭复用会重新整理全文。
- 单条问答本身或自定义提示词超出单次预算时，不截断、不把一轮伪装成多轮；会明确提示。需提高输入预算并选择更长上下文模型，或缩短自定义提示词。
- 分段降低单次峰值，不保证首次处理总 Token 更少：提示词和少量摘要需要重复发送。进度显示已处理轮数、已完成段数及复用轮数；费用以服务商账单为准。
- 账户余额不足、每分钟限流或账户总额度不足，不能靠分段消除；插件会停止并显示错误。模型不支持 JSON 模式时可关闭后重试。

为避免本机内存无限增长，仍保留 1 万轮／2000 万字符的本机处理保护。这不是模型上下文额度；超过时会停止，不悄悄丢弃正文。

每个任务固定对话、分支、正文快照、模型和提示词。切换网页、关闭侧栏不取消任务。新内容在旧任务后处理；开始时会复用前一任务刚完成的有效进度。旧轮次修改会从受影响轮次重建，之前的摘要只取未变化轮次，避免混入后续事实。浏览器或扩展重启后，中断或排队任务标记为已中断；在资料库设置中点击“续做”。浏览器关闭期间不运行。

## 文件夹资料库与自动整理

1. 在侧栏点击“资料库设置”。在独立的扩展设置页点击“选择 / 更换文件夹”，建议选择或新建 `C:\Users\chen\Documents\Topic Atlas`。
2. 路径备注可以由使用人修改，但仅输入路径不会授权。浏览器仅返回所选文件夹名称，不提供真实完整系统路径；实际写入位置由文件夹选择器决定。
3. 选择后自动复制浏览器记录并逐文件读回校验。更换目录默认同时复制旧资料库的全部历史版本，也可取消该选项；浏览器原记录与旧文件夹保留。已有资料库中的记录也会载入浏览器。
4. 授权信息存于扩展的 IndexedDB。若浏览器重启后要求授权，在本页点击“重新授权并同步”；后台不会弹权限框。授权失效或写盘失败显示错误，缓存和已完成进度保留，暂停有关任务，修复后手动续做。
5. 自动整理默认等待 30 秒：读取到明确的 AI 回复完成状态，且内容保持不变后触发；新消息重置计时。也可选回复完成后尽快整理、调整为 5—3600 秒，或关闭。网页读取间隔、浏览器休眠可能带来额外延迟。
6. 每条对话第一次须手动点击“抽取关系图”，之后才启用自动整理。无变化不调用 API；自动任务复用有效旧结果，只处理新增轮次。修改旧轮次重建其后内容；更换模型、服务或提示词重新整理。Gemini 暂无明确完成信号时须手动抽取。
7. 后台逐段运行，全局串行，侧栏显示任务总数；设置页显示各任务已完成与剩余轮数，支持取消、续做。失败不反复自动调用，可能已经扣费的未保存段落在续做时会重发。需放弃失败任务时可取消，让后续任务继续。
8. 历史版本按对话选择并列出。恢复前校验文件哈希且备份当前版本；恢复只修改本地、暂停该对话自动整理，不修改平台消息。自动读取仍可能将网页内容同步回来；如需长期查看旧版，请暂停顶部自动读取。恢复前先取消该对话的排队或运行任务。
9. “删除此记录”删除浏览器缓存并取消有关任务、暂停自动读取；资料库历史备份保留，可在设置页恢复。JSON 导出仍可用，包含本地对话和分析版本，不含 Key。

资料库文件结构：

- `topic-atlas.json`：目录索引，保存对话标题与子目录对应关系。
- `conversations/<对话标识>/index.json`：版本列表。
- 每个版本目录包含 `source.json`（正文、消息树、分支和标注）、`analysis.json`（图与分段结果）、`progress.json`（该对话任务及其固定快照）、`commit.json`（完成标记与 SHA-256 校验值）。
- 只有所有版本文件写入关闭并读回核验后才更新索引。历史备份不自动删除，资料库会随会话和任务积累而增大。
- API Key 不写入以上文件；原对话可能包含用户自己输入的敏感内容，请按普通私人文件管理资料库。
- 扩展新增 `alarms`（持久计时）和 `unlimitedStorage`（对话缓存与任务进度）权限，不新增浏览历史或 Cookie 权限。

## 一轮只显示一个 You 和一个 AI

- 以一次用户提问到下一次用户提问为范围，将连续的用户文本片段合并为一个 You 节点。
- 同一次回复中的 AI 分段合并为一个 AI 节点，原始消息 ID 和片段仍保留在导出数据中。
- 标明为隐藏上下文、用户系统信息或内部分析的消息不作为正文展示。
- 当前未完成的一轮可以暂时没有 AI 回复，不补造正文；后续回复完成时会自动更新。
- 旧版未识别角色的文本仍明确标记，不会强行凑成问答。ChatGPT 重新自动读取后使用结构化快照。

## 自动读取

- 默认开启。打开已保存的 ChatGPT 对话即自动读取，即使侧栏未打开也会保存到本机。
- 后台标签页会在切到前台时读取，避免同时请求所有后台对话。
- 切换对话自动跟随；新对话从草稿变为已保存地址后也会自动读取。
- 网页出现新回复时更新，最多约每 15 秒刷新一次，不要求滚动遍历全文。
- 顶部“自动读取”开关可以暂停或恢复，设置在当前浏览器配置中持久保存。
- 401、403 或未知数据结构等错误会停止该页的持续读取，避免反复请求。解决网页问题后，可关闭再开启自动读取，或刷新网页重试。
- 删除本机记录时会同时暂停自动读取，防止被立即重新保存。之后主动开启开关会重新读取已打开的对话。
- 只读取实际打开的支持站点对话，不后台遍历整个账号的历史列表。

## 定位原消息

每个 You / AI 节点下都可以直接点击“定位原消息”，无需先展开。查看历史记录时，会优先切到已打开的原对话标签页；没有对应标签页则打开记录中的原始对话地址，等待连接后再定位。

1. 优先匹配原始消息 ID。
2. 其次匹配原文，兼容常见 Markdown 格式标记、中文换行、空白差异及被拆入多个 div/span 的正文；长回复也可通过多个正文片段匹配。存在重复且无法区分的文本时不随意选择。
3. 若节点尚未加载，自动寻找对话滚动区域，按位置、已加载 ID 或正文片段尝试加载目标。不要求滚动容器具有特定类名。
4. 找到后滚动居中并高亮；查找失败则恢复搜索前的滚动位置。
5. 操作原网页（滚轮、点击或键盘）可取消正在进行的搜索。

自动查找有次数上限，不保证适配所有虚拟滚动实现。其他分支在网页尚未打开时会明确提示，不会随意点击 ChatGPT 的版本切换或新建分支按钮。侧栏中的分支选择只切换本机视图，原网页不受修改。

## 两个视图

- 时间线列表：每轮一个 You 和一个 AI。点击正文可展开，点击“编辑”可填写主题名称、总结和关系。
- 关系图：相同主题名合并，展示推进、分支和回归。点击主题定位到本机时间线。
- 对话分支下拉框：查看接口返回的不同路径。分支正文不会混成同一轮问答。
- 主题可手动编辑，也可以点击“抽取关系图”生成；人工标注优先保留。AI 连线标明原文依据或上下文推断，摘录经过逐字校验，语义判断仍需你核对。

## 完整性与隐私

- 在 ChatGPT 页面内，用当前登录状态请求当前会话的结构化数据，读取正文、author.role、ID、父子关系及原始时间（若有）。
- “已读取接口返回的消息树”不保证包含平台未返回、已删除或已覆盖的历史版本；父链不完整会明确显示部分读取。
- 有图片、音视频等明确标记的节点才计为非文本内容；保留可用文字，不能声称解析了附件正文。
- 空消息节点跳过，不计为附件；暂不能解析的其他格式单独统计并标为部分读取。
- 未连接文件夹时，正文、分支和主题暂存浏览器。连接后正式资料库写到已授权目录，浏览器保留工作缓存与任务日志，不使用同步存储。首次手动抽取后，按设置自动向所选 API 发送新增轮次。
- 登录令牌仅在 ChatGPT 页面函数内临时使用，不返回扩展、不写日志、诊断或保存记录。
- 不申请 Cookie 或浏览器 history 权限，不绕过登录和访问验证。API 站点为按需授权，安装时不会主动获得所有 HTTPS 站点的权限。
- JSON 导出包含所有已读取分支及原始片段；暂不支持导入。卸载扩展前请先备份。

## 排障和验证范围

## 请求层更新（v0.8.0 历史说明：能力必填规则已于 v0.9.1 取消）

### 先核对模型能力

设置 → 模型 API → 获取模型列表。服务商返回明确的上下文窗口及最大输出字段时自动填入当前模型。标准模型列表可能只有 ID；字段为空时，按实际服务商说明填写上下文、最大输出、可选独立输入上限及依据，并确认后保存。能力绑定 API 基础地址和模型；更换模型或服务地址需重新核对。中转站同名模型不能直接套用官方服务能力。

旧配置没有能力依据时，不发送新的整理请求。连接测试仍可使用简短请求测试认证与格式，不代表上下文能力已经验证。保存后点击“抽取关系图”新建任务，不要续做锁定了旧配置的任务。

每次完整请求检查成本估算与保守 UTF-8 字节计量，预留实际输出额度和上下文安全余量；包含系统提示、JSON 包装、目录、记忆、重叠和补读。计量不是服务端精确 Token 数，可能提前分片。模型输出限额同时约束不可见生成，不等于保证同等长度的可见 JSON。

### 长正文与补读材料自动分片

优先发送完整轮次。单轮或补读、旧摘要超出额度时，按段落、句子、代码块边界分片；不可完整容纳的代码块继续拆分。每片保留消息、角色及原文位置，带最多约160个 UTF-16 单位的重叠原文、累计记忆、用户归纳偏好和本次补读问题。重叠不重复计入事实，正文不会静默截断。UTF-16位置用于本地原文定位，不是 Token。

累计记忆要求保留名词指代、确认/建议/否定、矛盾和未解决问题，后文可修正前文。摘录逐条校验为本片连续原文并保存位置。必要时降低记忆目标长度再完整阅读，不把所有旧原文重新拼回请求；摘要是有损工作记忆，不保证语义无误。模型未按记忆长度或引用契约返回时仍会明确校验失败。

最终关系归纳使用累计记忆与可验证摘录，仍按原始消息全文校验引用，一轮保持一轮。记忆不足可申请回读本段指定消息和范围，最多2次，仍不确定时暂停并保留旧图。不能跨分支或把旧主题摘要当原文证据。首次没有主题时直接读第一批原文；后续仍保持目录 → 摘要 → 必要原文补读的顺序，补读过长进入相同分片流程。

### 进度与边界

后台每完成一片即保存检查点、用量和证据位置，随后继续调度；未读完不计作完成轮次，不提前发布图。设置的后台任务显示分片进度。浏览器关闭期间不运行；重启仍需明确续做，可能再次发送已发出但未保存的片段。新任务只复用来源、模型与提示词仍兼容的分片。改正文会失效对应记忆。

固定提示词与最低必要信息本身超过模型可用空间、能力未知、接口故障或输出校验失败时，仍需明确处理，不能靠无限拆分解决。现有历史目录/补查次数保护仍保留。分片、补读及回读会增加模型请求次数与费用。

依据：OpenAI模型对象接口 https://developers.openai.com/api/reference/resources/models/methods/retrieve ；输出与不可见Token计量 https://developers.openai.com/api/docs/guides/token-counting 。能力值仍以实际服务商为准，未内置猜测的模型容量表。

# 对话脉络 v0.9.3 · 正式请求等待时间

此前正式归纳、历史选择、简介补齐及分片阅读都固定在单次请求180秒后取消。这个上限覆盖等待与接收完整回复的总时间，即使服务已经开始流式输出也会触发。短连接测试正常，不能证明复杂归纳能在该时间内完成。

- 正式模型请求默认最多等待600秒（10分钟）。API设置新增“单次请求最长等待（秒）”，可设60—1800秒。
- 获取模型列表仍使用独立20秒上限，连接测试仍使用独立60秒上限。更改正式请求设置不改变这两项。

- 延长等待不会直接提高模型速度，也无法取消服务或浏览器自身的中断限制。不更改模型、输入预算、输出长度和每段轮数。
