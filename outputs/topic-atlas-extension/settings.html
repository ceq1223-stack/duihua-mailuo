连接模型 API

默认临时保留，浏览器或扩展重启后需重填。勾选记住后保存在扩展本地存储（未加密）；不会写入对话导出或采集诊断。网页内容脚本无法读取。

测试连接会向所选模型发送一条简短请求，确认能正常回复；不发送对话内容，可能产生少量 API 费用。测试不会保存设置。

无需填写模型上下文容量。能力信息可由接口提供，没有也可以开始整理。

默认10分钟，包含等待模型和接收完整回复的总时间。连接测试是简短请求，仍最多等待60秒；正式整理可能更慢。超时保留已完成进度，不自动重发；可手动取消。服务或浏览器仍可能提前中断。

长对话优先按完整轮次分段；单轮正文或补读过长时自动轮内分片，携带重叠原文与累计记忆，仍合并为原轮次。输入预算包含提示词和摘要，属于估算；每次完整请求按已核对的模型能力预留输出与安全空间，用户预算只控制成本，不作为模型能力。分段会产生多次 API 调用，长度不足时会缩小当前段后重试；原文引用错误最多校正一次，可能增加调用费用。关闭复用可重新整理全文。

使用 Chat Completions 兼容接口。若模型不支持 JSON 模式，可关闭后重试。模型、额度和权限以你的 API 账户为准；ChatGPT 网页订阅不能代替 API Key。

正在读取设置…

首次设置：点击下面的“选择 / 更换文件夹”，在弹窗中选择或新建“文档”中的 Topic Atlas 文件夹，并允许访问。路径文字仅作备注，填入路径不会自动连接。

浏览器中的现有记录始终会复制并逐文件校验；原记录和旧目录保留。首次连接也可读入已有资料库。

“重新授权并同步”用于已经选择过文件夹、但访问授权失效的情况。实际位置以文件夹选择器中授权的目录为准，浏览器不会提供完整系统路径。

关闭设置页后的授权：选择文件夹时可能只获得临时访问。若关闭本页后侧栏提示授权结束，请重新打开本设置页，在资料库中点击“重新授权并同步”。浏览器弹窗若提供“每次访问都允许”，请选择该项。插件无法强制永久授权；Edge 的版本或策略可能影响选项。仅重载本页不一定触发持久授权提示。授权结束时新内容留在浏览器，恢复后统一同步；失败或中断的 AI 任务仍需手动续做。

自动整理

默认 30 秒。新消息会重新计时；没有内容变化不调用 API。首次请在侧栏手动抽取，此后这条对话才会自动整理。自动整理会向已配置的模型 API 发送新增对话，并可能产生费用。

当前优先支持 Edge 中的 ChatGPT。只有读取到明确的回复完成状态才自动触发；Gemini 等无法确认完成状态的记录可手动整理。浏览器休眠可能延迟触发。

后台任务

历史记忆：先让模型查看全部主题的简短目录，再读取选中主题的完整摘要；需要时补查旧轮次原文，每段最多补查 2 次。目录会按预算分页，无法完整查看或模型不确定时暂停。选择目录和补查后的归纳会增加 API 调用；详情在每个任务下展开查看。当前仅核对结构、标识和原文引用，不保证语义判断无误。

关闭侧栏、切换对话不会取消已排队任务。浏览器关闭期间不运行；扩展重新启动后，中断任务需要点击“续做”。取消和失败保留已完成的段落。续做使用该任务创建时的设置，可能再次发送中断前尚未保存的一段。要采用当前模型、提示词或预算，请回侧栏点击“抽取关系图”新建任务；只复用兼容进度。失败任务只暂停自身，不阻挡新任务。

历史版本与记录详情

恢复只修改本地记录，不修改 ChatGPT 网页。后续自动读取可能再次同步网页内容；恢复前会保留当前版本，并暂停这条对话的自动整理。
