# 对话脉络 v0.7.3

修复旧失败任务阻挡同一对话的新任务，以及新抽取错误沿用旧预算的问题。

- 点击“抽取关系图”按当前设置创建新任务，不重新激活旧失败任务。
- 失败/中断任务保留原状态和进度，只暂停自身，不阻挡其他已排队任务。
- 自动任务不重试相同正文与相同设置下已经失败的执行；新正文或新设置可形成新任务。
- 新任务只复用兼容进度。修改预算、输出上限和每段轮数可复用有效轮次；修改模型、提示词或原文时重新检查兼容性。
- 活跃任务以完整配置去重，避免把修改预算后的请求误判为同一个任务。
- “续做”仍固定原任务配置；设置页已说明与新抽取的区别。

验证：225 项模拟自动检查与 17 个 JavaScript 文件语法检查通过。未调用付费 API。单个超长轮次的内部切分仍未实现，本次不解决该预算限制。

安装后在 edge://extensions 重新加载扩展并刷新 ChatGPT。修改设置并保存后，直接点击侧栏“抽取关系图”，不必取消旧失败任务。
