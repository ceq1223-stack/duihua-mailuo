# 对话脉络 v0.7.10 · 消息标记诊断

为核对执行过程为何进入时间线，现有“复制采集诊断”按钮新增 messageMarkers 区块。

- 复用插件既有登录态读取链路，直接在网页内部提取结构类别，登录凭据不返回扩展诊断结果。
- 输出消息角色、通道、接收对象类别、内容块类型、工具调用字段、隐藏标记和路径顺序；未列入白名单的值只记 other。
- 不返回正文、消息 ID、工具参数、任意元数据值或凭据；不持久化诊断、不保存新对话、不触发整理模型请求。
- 仅扩展界面可以发起；自动读取暂停时也能诊断。读取期间切换对话会丢弃结果。
- 沿用现有采集、过滤、校验与整理逻辑，不自动删除消息或清理旧记录。

使用：重新加载扩展并刷新 ChatGPT → 打开《生成测试程序》→ 点击底部“复制采集诊断” → 将结果发回。复制失败时可在下方选中文本手动复制。重点核对 messageMarkers，若只有 error 请一并提供。

验证：298 项模拟检查通过，18 个 JavaScript 文件语法检查通过；未调用付费 API。真实对话的原始标记尚待更新后实际采集，不将模拟标记当作已验证的平台标记。
