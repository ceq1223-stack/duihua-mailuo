# 对话脉络 v0.9.0 · 最新 Demo 阅读体验

按 2026-10-29 本地 topic-atlas-showcase Demo 更新插件。移植阅读交互与配色，没有复制演示对话，也没有增加展示网站的宣传区域。

## 页面与导航

- 暖白背景、森林绿主题卡片、珊瑚红路径端点。侧栏与展开页共用画布，继续支持拖动、缩放、搜索、主题目录和回归线开关。
- 主题详情保留“主题详细摘要 · AI 归纳”；讨论记录使用 R 编号与标题。点击标题跳到时间线的对应轮次并展开，不依赖标题文字匹配。
- 时间线按轮次折叠，展开后继续支持按需读取正文、原消息定位和长正文分页。检索使用本地已有标题、主题、摘要与预览，不会为搜索读取整份原文或请求模型；不承诺全文搜索。跳转会清空过滤，确保目标可见。
- 保留上一版的可见区域渲染、轻量索引与进度通知，完整原文及导出不删减。

## 未展开与待继续路径

- 未展开方向用小红点表示，名称在悬停或键盘聚焦时出现；明确暂搁的问题用“待继续”虚线端点表示。端点不是主题，不计入已讨论主题数。
- 点击端点查看说明、真实来源摘录、对应 R 编号与标题，可跳回时间线。只接受存在于对应轮次和角色中的连续原文。
- 支持加入待办、移出待办、完成待办、暂不考虑、恢复方向。人工状态与讨论状态独立；完成待办不会把红点变成已讨论主题。
- 人工状态按会话、分支、来源身份保存到本地记录，并沿用既有文件夹保存、备份和导出链路。未授权或写盘失败时，以设置中的实际保存状态为准。重开浏览器不依赖网页内存恢复；来源变更时会阻止对旧端点进行操作。
- 模型在后续正文中找到实质展开的证据时，可以将已提供的历史路径更新为已展开，并关联到已有主题；画布收起对应端点。程序核对标识与原文，语义判断仍可能有误。

## 模型输出与升级说明

新请求在现有输出契约上增加 directions 和 directionUpdates 数组。没有明确方向时必须返回空数组，不为了凑红点生成建议。方向包含来源主题、类型、标题、说明、来源轮次及原文证据；展开更新也需要目标主题、发生轮次和本段原文证据。

旧关系图继续显示，升级不会调用模型替你重建历史，也不能凭空补出旧图没有的端点。要识别已有对话的历史方向，请主动点击“抽取关系图”新建任务。新增契约与旧版检查点不等价，首次新任务会从头归纳并产生 API 费用；原图保留至新结果通过校验。升级前已排队的旧任务如不打算继续，可在后台任务中取消。

后续同版本兼容进度仍可增量复用。历史方向记忆跟随已选择的历史主题，每次最多提供24项轻量目录并标记覆盖范围；不声称扫描全部历史方向，不因没匹配就判定已经展开。较长正文仍走已有分片与补读链路。
