# 对话脉络 · Topic Atlas

Topic Atlas 是用于整理个人 AI 对话的浏览器扩展。当前源码版本为 **v0.9.3**，优先适配 Edge + ChatGPT；Gemini 的兼容能力仍需实际页面验证。

[在线体验 Demo](https://ceq1223-stack.github.io/topic-atlas-demo/)：使用改写示例体验时间线、主题关系图和未展开路径，不读取账号或调用模型 API。

## 使用

1. 在 Edge 打开 `edge://extensions`，启用开发人员模式。
2. 选择“加载解压缩的扩展”，选择本项目的 `outputs/topic-atlas-extension` 文件夹。
3. 打开 ChatGPT 对话和扩展侧栏；在设置中授权本地资料库文件夹。
4. 选择模型 API、填写自己的 Key，使用连接测试后保存。
5. 点击“抽取关系图”。自动增量整理启用后，默认等待回复稳定 30 秒。

只保留时间线和关系图两个主视图。时间线按轮次折叠并支持标题检索，关系图显示有原文证据的未展开方向与待继续路径；人工待办独立保存。历史关系图在新的结果完成前继续显示。主题具有名称、简短说明、详细摘要和原文证据；历史记忆支持模型选择相关主题与按需补读。

## 项目文件

- `outputs/topic-atlas-extension/`：可加载的扩展源码与使用说明。
- `demo/`：独立演示的维护源码、构建脚本和静态页面。
- `work/test-*.cjs`、`work/history-fixture.cjs`：使用模拟数据的自动检查。

## 验证

安装 Node.js 22 或更高版本后，在项目根目录执行：

```text
npm test
```

测试仅使用 Node.js 内置模块，不调用付费 API。当前基线为 415 项自动检查。真实 Edge 登录页面、目录权限生命周期和付费 API 仍需手动验证。已支持轮内与补读分片；无需手填模型上下文；能力未知时按输入预算规划，接口超限时缩段或分片。

## 数据与隐私

仓库只包含代码、文档和测试数据。API Key、个人对话资料库、浏览器缓存与本机历史备份不属于仓库内容。使用者自行配置资料库与 API；模型归纳会将选定内容发送至所选 API 服务。目录与浏览器授权行为详见扩展使用说明。
